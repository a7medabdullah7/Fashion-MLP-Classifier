# Fashion MLP Image Classifier

## Project Description

This project classifies Fashion MNIST images using a Multi-Layer Perceptron (MLP) built with TensorFlow and deployed using Streamlit.

## Dataset

Fashion MNIST Dataset

## Technologies

- Python
- TensorFlow
- Streamlit
- NumPy
- Pillow

## Run Locally

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

## Model

MLP Neural Network

## Test Accuracy

86.85%
